# Asosiy sahifa (portal) hero foni

Shu papkaga tayyor fayllarni qo‘ying — sayt avtomatik ishlatadi (kod o‘zgartirish shart emas):

| Fayl | Nima | Talab |
|---|---|---|
| `portal.jpg` | Hero surati (video bo‘lmasa yoki video yuklanguncha ko‘rinadi) | 16:9, 2560×1440, ≤ 400 KB (JPEG, sifat ~80) |
| `portal.mp4` | Hero videosi (ixtiyoriy) | 16:9, 1920×1080, H.264, 6–10 s, uzluksiz takrorlanadigan (loop), ovozsiz, ≤ 8 MB |
| `portal-m.mp4` | Telefon uchun yengil video (ixtiyoriy) | 9:16 yoki 4:5, 720p, ≤ 3 MB |

Hech narsa qo‘yilmasa, `/media/stories/santexnika/film.*` ishlatiladi.
Matn sahifaning markazida turadi: suratning markazi tinch va ochiqroq bo‘lsin, qiziqarli tafsilotlar o‘ng tomonda va chuqurlikda.
