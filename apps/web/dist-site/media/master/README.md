# Usta hikoyasi uchun haqiqiy kadr (ixtiyoriy)

Usta landing'idagi 01-sahna («Siz o‘z ishingizning ustasisiz») shu yerdagi videoni ijro etadi.
Fayl bo‘lmasa — asboblar illyustratsiyasi ko‘rsatiladi (soxta foto qo‘yilmaydi).

```
work.mp4     # desktop (≤ 1080p, 8–15 soniya, loop, ovozsiz)
work-m.mp4   # telefon (≤ 720p)
```
Kadr: usta qo‘llari, asboblar, material, haqiqiy ish joyi — yaqin plan. Mijoz hikoyasi bilan bir xil odam/uy ishlatilmasin.
